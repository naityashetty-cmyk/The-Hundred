# 🏏 The Hundred: Pro Cricket League

The Hundred is a high-speed, strategic cricket game played through the "Hand Cricket" method. Can you lead your team to the trophy?

## 🚀 [CLICK HERE TO PLAY THE GAME](https://naityashetty-cmyk.github.io/The-Hundred/)

---

## 🎮 Game Features
* **Select Your Franchise:** Pick from 4 elite teams.
* **Live Commentary:** Every ball described as it happens.
* **Win Probability:** Real-time data analytics showing who is in control.
* **League Standings:** Watch the points table update as other matches auto-simulate.
* **Grand Final:** Top two teams face off for the championship!

## 🕹️ Controls
* **Batting:** Click a number (1-6). If you match the CPU, you're out!
* **Bowling:** Guess the CPU's number to take a wicket.
* **Super Over:** If the game ends in a tie, a 6-ball thriller begins.
